SOVEREIGN ARCHITECTURE & CLI

What It Does & How It Works

Local-Only Security

Bound strictly to 127.0.0.1:8152. OAuth 1.0a secrets stay in ~/.config/zoth-vault/x.env (chmod 600) and are never serialized to the browser or committed to git.

Persistent 5× Daily Timer

Controls x-multi-hub.timer with Persistent=true and user lingering so scheduled slots survive terminal exits and reboots.

ZothOS CLI

Run zoth-x-connector --status, zoth-x-connector --json, zoth-x-connector run, or zoth-x-connector timer start|stop from any terminal.
